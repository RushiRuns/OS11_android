# ADR-A11: Rich text note editor: Drop compose-rich-editor, adopt lightweight AnnotatedString editor + Jsoup

Status: Accepted (2026-10-10)

## Context
Desktop stores task notes as sanitized HTML generated by its TipTap (ProseMirror-based) rich text editor. The HTML subset includes headings (`<h1>` to `<h6>`), bold (`<strong>`), italic (`<em>`), strikethrough (`<s>`), underline (`<u>`), bullet lists (`<ul><li>`), ordered lists (`<ol><li>`), task lists / checklists (`<ul data-type="taskList"><li data-type="taskItem" data-checked="...">`), links (`<a>`), inline code (`<code>`), code blocks (`<pre><code>`), and blockquotes (`<blockquote>`). Notes are synced bi-directionally between desktop and Android via LAN sync.

Spike S-2 evaluated `compose-rich-editor` against real desktop TipTap HTML payloads. The evaluation identified a critical failure: `compose-rich-editor` silently strips unsupported attributes (notably `data-type="taskList"`, `data-checked="true"`, custom link attributes) and alters node hierarchies upon serializing back to HTML, resulting in permanent data loss for notes edited on Android.

## Options considered
1. **`compose-rich-editor`**: Third-party Compose rich text library. High risk of silent content loss during HTML parsing and serialization round-trips. Heavy reliance on custom spans and unstable APIs.
2. **WebView running TipTap / bundled web editor**: Full parity with desktop TipTap. Violates ARCHITECTURE.md Rule 11 and PERFORMANCE.md startup and memory limits. High process memory, slow initialization, IME/touch keyboard friction on mobile.
3. **Custom lightweight editor over `AnnotatedString` + Jsoup sanitization**:
   - Parse incoming HTML into Compose `AnnotatedString` using Jsoup, preserving standard inline marks (bold, italic, strikethrough, code, links) as SpanStyles.
   - For block structures (headings, lists, blockquotes), maintain structured paragraph styles.
   - For custom TipTap nodes (such as task lists with `data-type="taskList"`), preserve tags and attributes deterministically or cleanly map them without silent stripping.
   - On save, sanitize and reconstruct clean HTML using Jsoup (`org.jsoup:jsoup`).

## Decision
Drop `compose-rich-editor`. Drop WebView. Adopt a custom minimal Compose editor over `BasicTextField` / `AnnotatedString` combined with Jsoup for deterministic HTML parsing, node preservation, and sanitization for Phase 5.

## Consequences
- Zero risk of silent note truncation or attribute loss across sync boundaries.
- No heavy runtime overhead, foreign process, or memory bloat from WebView.
- Clean Compose native text editing with full accessibility and IME keyboard support.
- Jsoup is approved in `DEPENDENCIES.md` as the Android equivalent to desktop's DOMPurify.
